# Отчёт по проекту Tamsun Group

Проект: интернет-витрина премиальных сувениров Tamsun Group (Астана).  
Форма работы: сайт с каталогом, корзиной, заявкой в WhatsApp и админкой.  
Упаковка: Docker-образ `tamsun:latest`.

## 1. Что делает система

Покупатель открывает сайт, смотрит товары и услуги, кладёт изделия в корзину и оставляет имя и телефон. Заявка сохраняется на сервере, после этого открывается WhatsApp с готовым текстом. Оплаты на сайте нет: это заявка, а не платёж.

Администратор входит по паролю, правит каталог, смотрит заказы и клиентов, скачивает PDF-каталог и счёт.

## 2. Из чего состоит проект

| Часть | Технология | Роль |
| --- | --- | --- |
| Витрина и админка | React 19, Vite 7 | Страницы магазина, корзина, форма заявки |
| Сервер | PowerShell, HttpListener, порт 8765 | API, раздача сайта, проверка доступа |
| База | SQLite, файл `data/tamsun.sqlite` | Товары, заказы, клиенты |
| Чат и PDF | Node.js | Ответы консультанта и документы |

Цены в заявке считает сервер по базе. Цена, которую прислал браузер, не принимается как итоговая.

## 3. Надёжность и безопасность

Сделано и проверено до упаковки в Docker:

- Сервер не запускается, если не задан пароль администратора `ADMIN_PASSWORD`. В коде нет запасного пароля.
- Запрос с чужим адресом сайта получает ответ 403. Свои адреса задаются переменной `TAMSUN_HOSTS`.
- Если тело запроса не приходит за 5 секунд, соединение закрывается с ответом 408.
- При ошибке загрузки каталога на сайте нет выдуманных товаров. Показан текст «Не удалось загрузить каталог. Пожалуйста, обновите страницу» и кнопка «Повторить».
- Ошибка отрисовки React не оставляет белый экран. Показан текст «Что-то пошло не так. Попробуйте перезагрузить страницу».
- Заказ и карточка клиента записываются одной транзакцией. Если карточка не сохранилась, заказ откатывается и клиент получает ответ 500.
- Заявка длиннее 30 позиций не обрезается молча: сервер возвращает ошибку.
- Счёт использует курс доллара, который был сохранён в заказе.
- Ошибки сервера пишутся в `data/tamsun-error.log`. Наружу не отдаются пароль, SQL и стек вызовов.

## 4. Как проект упакован в Docker

Образ собирается в два этапа.

1. `node:22` собирает витрину командой `npm run build`. Результат лежит в папке `dist`.
2. Итоговый образ на Debian содержит Node.js, PowerShell 7 и библиотеку SQLite для Linux. Внутри запускается тот же `server.ps1`.

Сервер внутри контейнера слушает все сетевые интерфейсы контейнера (`TAMSUN_BIND=+`). Снаружи открыт порт 8765. База заказов хранится в томе Docker `tamsun-data`, поэтому заказы не пропадают при перезапуске контейнера.

Файл `.env` и папка `data` в образ не копируются. Пароль и ключ чата передаются только при запуске.

Размер готового образа: около 1,9 ГБ. В него входят среда выполнения, сайт, фотографии и видео мастерской.

Файлы упаковки:

- `Dockerfile` — сборка образа
- `docker-compose.yml` — запуск и том с базой
- `.dockerignore` — исключает секреты, локальную базу и `node_modules`

## 5. Проверка контейнера

Проверено на этой машине после сборки образа `tamsun:latest`.

| Проверка | Результат |
| --- | --- |
| Запуск без `ADMIN_PASSWORD` | Контейнер сразу останавливается с текстом «Критическая ошибка: ADMIN_PASSWORD не задан в переменных окружения», код выхода 1 |
| `GET /api/catalog` с паролем | Ответ 200, в каталоге есть товар `bes-qaru` |
| Главная страница | Ответ 200, на странице есть корень приложения |
| Запрос с заголовком `Host: evil.example` | Ответ 403 |

Каталог в чистом контейнере создаётся из начальных данных. Живая база с этого компьютера в образ не входит.

## 6. Как запустить

На компьютере должен быть установлен Docker Desktop.

В PowerShell, в папке проекта:

```powershell
$env:ADMIN_PASSWORD = "длинный-пароль"
docker compose up --build
```

Сайт открывается по адресу `http://127.0.0.1:8765/`. Админка: `http://127.0.0.1:8765/admin`.

Если порт 8765 уже занят локальным `server.ps1`, этот процесс нужно остановить. Иначе Docker не сможет занять тот же порт.

Чат с моделью работает, если при запуске задана переменная `OPENAI_API_KEY`. Без неё магазин, корзина и заявки работают, а консультант остаётся на локальных ответах.

Остановка:

```powershell
docker compose down
```

Том `tamsun-data` при этом сохраняется. Команда `docker compose down -v` удаляет базу заказов.

## 7. Что остаётся за пределами контейнера

Сайт в контейнере открывается по HTTP. Для публичного адреса сертификат HTTPS ставится на прокси перед контейнером, а имя сайта передаётся в `TAMSUN_HOSTS`.

Пока сервер собирает PDF, остальные запросы к этому же процессу ждут окончания сборки.

Если в настройках нет курса доллара, для пересчёта используется значение 500.
